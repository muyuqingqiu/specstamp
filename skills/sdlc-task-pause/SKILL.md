# sdlc-task-pause

命令：`codex-sdlc task-pause`

执行时请：

1. 只暂停当前 `doing` 任务，把它退回 `todo`。
2. 用户明确给出任务时，执行 `codex-sdlc task-pause REQ-001 T-004 --reason "原因"`。
3. 用户只说“停下”“这个任务不对”时，按本会话最近启动的 `doing` 任务判断；多个高度相关时询问用户。
4. 暂停前先看 Git 改动；如果已有业务代码改动，先提醒用户保留现场并确认是否继续暂停。
5. 本阶段只改任务状态，不写代码、不跑测试、不提交代码、不插入新任务。
6. 暂停后必须停下，输出任务状态和下一步建议。
7. 如果暂停原因是“怀疑一批已完成任务质量”，下一步推荐 `$sdlc-audit`。
