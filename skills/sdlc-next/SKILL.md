# sdlc-next

## 输入

- 当前项目事件、正式产物、审核记录、任务合同和任务运行轮次。
- 直接执行：

`codex-sdlc next`

## 执行

1. 原样读取主推荐、原因和备选动作，不手工重排。
2. `planning_tasks` 只推荐补齐任务输入、清空阻塞项或完成当前整套任务审核。
3. `ready_for_development` 只按正式依赖和当前有效审核推荐 `codex-sdlc task REQ-001 T-001`。
4. `developing` 中，当前轮次为 `reading` 时推荐同任务读取确认；为 `active` 时推荐继续当前任务或在门禁满足后收口；为 `stale`、缺失或身份冲突时给出明确停止原因。
5. `verifying` 只推荐需求级回归和验收；`accepted` 不再推荐开发任务。
6. 存在当前结构化 CHG 时，只推荐该工作区允许的正式变更动作，不回退到自然语言写入入口。

## 输出

- 一个正式主推荐。
- 与当前需求、任务、审核或运行轮次对应的明确原因。
- 必要时提供不会绕过门禁的备选动作。

## 阻塞条件

- 状态投影损坏、正式引用漂移或事务尚未恢复。
- 多个活动任务运行轮次互相冲突。
- 当前审核、读取清单或任务运行轮次无法确定。
- 推荐动作与 `codex-sdlc status` 展示的结构化状态不一致。

## 审核点

本技能不创建审核。推荐任务开工前必须已有当前有效 `task_plan` 审核；推荐变更继续前必须满足 `review_impacts` 指定的正式审核。

## 停止位置

只输出当前一步并停止。没有用户授权或 Goal 调度时，不执行推荐动作，不连续猜测后续阶段。
