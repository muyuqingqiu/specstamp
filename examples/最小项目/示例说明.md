# SpecStamp 最小可运行示例

这个示例使用一份待办清单需求资料，真实执行以下流程：

1. 在临时目录初始化 SpecStamp；
2. 创建 `DRAFT-001`；
3. 把需求原文归档到 DRAFT；
4. 根据当前结构化状态输出下一步建议。

## 运行前提

- macOS 或 Linux 等 POSIX 系统；
- 已安装 `specstamp` 命令；
- Python 3.10 或更高版本。

## 运行

在仓库根目录执行：

```bash
sh examples/最小项目/运行示例.sh
```

脚本会创建一个新的临时目录，并在结束时打印绝对路径。运行结果不会写入当前仓库，也不会同步 Agent 全局入口。

从源码开发时，可以显式指定仓库入口和受管 Python：

```bash
CODEX_SDLC_PYTHON=/绝对路径/venv/bin/python \
SPECSTAMP_BIN=/绝对路径/specstamp/bin/specstamp \
sh examples/最小项目/运行示例.sh
```

需要固定结果目录时设置 `SPECSTAMP_DEMO_DIR`。目标目录不能包含已经初始化的 `.codex-sdlc/`：

```bash
SPECSTAMP_DEMO_DIR=/tmp/specstamp-example \
sh examples/最小项目/运行示例.sh
```

## 预期结果

命令应依次输出初始化目录、`DRAFT-001`、`MAT-001` 和当前下一步建议。生成的 `.codex-sdlc/` 目录包含事件记录、SQLite 状态库和便于阅读的 Markdown 投影。
